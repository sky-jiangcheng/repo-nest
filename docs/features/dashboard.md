# 仪表盘

仪表盘展示所有项目的每日提交统计、目标进度与全年提交热力图。

> **并入首页（ADR-0024）**：仪表盘面板现在是**首页工作台**的主体——打开应用直接就是本页内容；主导航以「搜索」取代「仪表盘」入口，旧 `/dashboard` 链接自动重定向到首页。本文标题保留「仪表盘」，指的就是首页上的这块项目状态面板（单栏自上而下，不再与记忆环两栏并排）。

## 页面结构（自上而下）

```mermaid
flowchart TB
    STRIP["记忆环条<br/>最近 handoff · 全局搜索入口"] --> RING["① 目标进度区<br/>进度环 · 摘要条"]
    RING --> HEAT["② 提交热力图<br/>近 52 周 · 点击跳当日"]
    HEAT --> CTRL["③ 控制区<br/>日期切换 · 联合搜索<br/>过滤 · 排序 · 重新扫描"]
    CTRL --> GRID["④ 项目网格"]
    GRID --> STAR["已收藏：完整统计卡片<br/>目标进度条 · 团队总量"]
    GRID --> PLAIN["未收藏：极简卡片<br/>名称 + 星标"]
```

读图：页面是**一条竖直的阅读顺序**，顶部一条记忆环条，往下四层自上而下。热力图（②）是全局时间视图，控制区（③）是它的操作面板（日期切换会同时改变热力图与项目卡片的口径），项目网格（④）按收藏状态分两种卡片密度——未收藏只给名称，想看统计得先点星标。三层都跟着 **git 作者配置**变（见[设置](settings.md#作者配置)）。

### 记忆环条（页首，ADR-0024）

首页最上方的一条横向记忆带：左侧是「记忆环」标签，中间是**最近的会话 handoff**（点击直达所属项目，自动捕捉的带「自动」徽标），右侧是**全局搜索入口**——点击进入独立的[全局搜索页](search.md)。没有 handoff 时显示占位提示；窄屏下手换行排列。

### 目标进度区

- **进度环**：今日（或所选日期）个人新增行数 vs 每日目标；非工作日不显示目标
- **副标题**：距达标差值、个人新增 / 文件数 / 涉及仓库数
- **摘要条**：团队新增 / 删除、个人新增 / 文件、待办总数

### 提交热力图

近 52 周每日提交密度（GitHub 风格），点击任意格子跳转到该日期查看当天项目数据。统计范围跟随当前 git 作者（设置 → 作者配置）。

### 控制区

- **日期切换**：昨天 / 今天 / 任意日期
- **联合搜索框**：实时搜索仓库、笔记与待办（防抖 300ms，结果可直接星标或跳转）
- **过滤器**：全部 / 仅收藏
- **排序**：名称 / 个人新增 / 文件数 / 仓库数
- **重新扫描**：两击确认后触发异步扫描，进度实时展示，完成后自动刷新数据

### 项目网格

- **已收藏仓库**：完整统计卡片（今日新增、目标进度条、仓库/文件/新增/删除、净增、团队总量、待办与笔记角标）
- **其他仓库**：极简卡片（名称 + 星标按钮），需要时再收藏展开

## 功能详解

### 仓库收藏

点击星标收藏仓库：卡片展开为完整统计，出现 **刷新历史** 按钮（按需回填近 365 天数据）。取消收藏立即折叠为极简卡片。

注意这与[快速开始](../getting-started.md)的上手路径是同一件事的两面：收藏**只为仪表盘统计**，不影响知识库可用性。

### 目标进度

**设置 → 代码标准** 配置每日目标行数（默认 500，范围 100-10000）。

- 进度环与卡片目标条显示完成度，达标显示 🎉
- 工作日未达标时卡片显示「未达标」告警；周末不告警

### 项目分组

自动按父目录分组（Monorepo 识别），手动拆分/合并见[项目详情](project-detail.md)。

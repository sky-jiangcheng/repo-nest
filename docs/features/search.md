# 全局搜索

全局搜索是一个顶级页面（ADR-0024）：一个输入框检索**全部项目的笔记、待办与项目名**，结果按「项目 / 笔记 / 待办」分组。导航栏「搜索」与首页记忆环条右侧的入口都会到达这里；⌘K / Ctrl+K 命令面板仍是键盘优先的快速切换器（首位动作是新建 handoff），两者共存。

## 页面结构

- **搜索框**：进入页面自动聚焦；输入防抖 150ms 后检索，查询同步到地址栏 `?q=`（可收藏、可从其他页面深链）
- **结果分组**：项目（名称匹配）/ 笔记 / 待办（FTS5 全文检索，关键词高亮），每组带计数
- **无结果**：给出提示，并建议从热门标签开始

## 空闲推荐

没有输入时，页面展示两类推荐（而不是一块空白）：

- **热门项目**（top 6）：按**最近个人新增行数**排序（取 `GetProjects` 默认的昨日口径），星标与仓库数作平局兜底；点击直达项目
- **热门标签**（top 12）：来自全部笔记的标签；**点击即把标签填入搜索框执行检索**

热门是客户端启发式排序（ADR-0024），口径以页面标注为准。

## 与其他搜索入口的关系

| 入口 | 范围 | 特点 |
|------|------|------|
| 全局搜索页 | 笔记 · 待办 · 项目名 | 顶级页，可深链，有空闲推荐 |
| ⌘K 命令面板 | 笔记 · 待办 · 项目名 | 键盘快速切换，首位动作新建 handoff（见[命令面板](command-palette.md)） |
| 首页控制区联合搜索 | 仓库、笔记与待办 | 结果可直接星标仓库（见[命令面板](command-palette.md)） |
